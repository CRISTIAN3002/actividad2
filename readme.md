# Cafetería Cristian - Proyecto Web Responsivo

## Objetivo de Aprendizaje
Construir y publicar un sitio web responsivo utilizando HTML5 semántico y CSS moderno, aplicando principios básicos de usabilidad, accesibilidad y validación de estándares.

## Descripción del Proyecto
Sitio web informativo para "Cafetería Cristian", que presenta la marca, el catálogo de productos disponibles y un formulario de contacto para clientes.

## Estructura del Proyecto
- `index.html`: Página principal con presentación y características.
- `productos.html`: Menú de productos diseñado con CSS Grid.
- `contacto.html`: Formulario de contacto accesible.
- `css/styles.css`: Hoja de estilos responsiva con Flexbox y CSS Grid.

## Tecnologías Utilizadas
- HTML5 Semántico
- CSS3 (Flexbox, CSS Grid, Media Queries)
- GitHub Pages para despliegue
- Validador W3C

## Resultados de Validación
- **HTML5:** Validado sin errores en el W3C Markup Validation Service.
- **CSS3:** Validado sin errores en el W3C CSS Validation Service.
